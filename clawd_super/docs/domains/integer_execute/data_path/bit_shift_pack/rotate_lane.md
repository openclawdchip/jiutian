# Rotate Lane

## 角色

这一层负责循环移位。它把位串在固定宽度内首尾相接，支持左旋和右旋两种方向。

## 输入

- `value`：待旋转值。
- `amount`：旋转位数。
- `width`：操作宽度。
- `left`：是否左旋。

## 输出

- `result`：旋转后的值。
- `carry_out`：边界位观察值。

## 状态

- 纯组合路径。
- 不依赖旧 flags，但可被上层 flag 入口复用。

## 处理流程

1. 将移位量归一到当前宽度。
2. 根据方向选择 `rol` 或 `ror`。
3. 结果按宽度截断。
4. 输出旋转边界位，供上层观察。

## 边界

- 旋转量为 0 时结果不变。
- 旋转量按宽度取模，不会溢出到下一位宽。

## 行为模型接口

- `rotate`
