# Booth Stage

## 角色

这一层负责乘法前端的 Booth 编码准备。它把 3-bit multiplier 窗口变成后续部分积生成可直接消费的控制码和数学倍数。

## 输入

- `src`：3-bit Booth 窗口。
- `width`：操作宽度。

## 输出

- `booth_code`：4-bit 控制编码。
- `window_multiplier`：窗口对应的数学倍数。

## 状态

- 纯组合逻辑。
- 不保存上一窗口历史，窗口重叠由上层控制。

## 处理流程

1. 读取当前 3-bit window。
2. 生成正、负、一次、两次四种控制位。
3. 映射成 `0 / ±1 / ±2` 的数学倍数。
4. 把结果交给部分积选择层。

## 边界

- `000` 和 `111` 都表示 0。
- `011` 和 `100` 对应 2 倍路径。
- 控制码和数学倍数是两种观察口径，不能混淆。

## 行为模型接口

- `booth_encode_radix4`
- `booth_window_multiplier`
