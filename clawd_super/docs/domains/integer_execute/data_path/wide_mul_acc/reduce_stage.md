# Reduce Stage

## 角色

这一层负责压缩归约。它把多路部分积逐层压成两个可继续累加的项，同时保留关键边界进位。

## 输入

- `partial_products`：部分积集合。
- `ppcin` / `ppucin`：压缩树注入位。
- `prod_is_32b` / `mul64`：结果宽度控制。

## 输出

- `pp0`：第一条压缩输出。
- `pp1`：第二条压缩输出。
- `cout48` / `cout80`：关键边界进位。

## 状态

- 纯组合压缩树。
- 不保留流水级状态，但要保留注入位和边界进位的观察关系。

## 处理流程

1. 把输入部分积切成若干 CSA 层。
2. 在中间层注入修正位。
3. 逐层压缩到两个输出项。
4. 输出边界进位，供末级窗口和 Q-bit 观察。

## 边界

- 8 路和 9 路压缩树的注入位置不同。
- 32 位和 64 位路径会影响中间层截断窗口。

## 行为模型接口

- `mac_4to2`
- `mac_6to2`
- `mac_8to2`
- `mac_9to2`
