# Window Stage

## 角色

这一层负责末级结果窗口选择与格式化。它决定最终写回时看低半、高半还是移位后的窗口，并把 128 位内部结果裁成可见结果。

## 输入

- `product`：128 位乘法或乘加结果。
- `width`：操作数宽度。
- `high`：是否选择高半结果。
- `result_shift`：窗口偏移。
- `doubleword`：是否按 64 位写回。

## 输出

- `result`：最终写回值。
- `formatted_result`：格式化后的窗口观察值。
- `selected_window`：被选中的窗口内容。

## 状态

- 纯组合选择。
- 所有状态都来自上层乘法/累加结果，不自持久化。

## 处理流程

1. 选择高半或低半结果路径。
2. 应用结果偏移。
3. 按 32/64 位写回宽度截断。
4. 输出窗口边界和符号观察值。

## 边界

- 高半选择优先级高于普通窗口偏移。
- 32 位和 64 位观察窗口不能混用。

## 行为模型接口

- `multiply`
- `multiply_accumulate`
- `_format_multiply_result`
