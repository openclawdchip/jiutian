# Flags Path

## 角色

这一层把算术结果转换成比较事实和标志观察值。它不改写数值结果，只负责把 eq/lt/le/gt/ge 以及 NZCV 语义整理好。

## 输入

- `a`：比较源 A。
- `b`：比较源 B。
- `signed_compare`：是否按有符号数解释。
- `width`：比较宽度。

## 输出

- `eq`：相等。
- `lt`：小于。
- `le`：小于等于。
- `gt`：大于。
- `ge`：大于等于。

## 状态

- 纯组合逻辑。
- 不依赖历史标志。

## 处理流程

1. 把输入限制到目标位宽。
2. 选择有符号或无符号解释。
3. 计算五类基础比较关系。
4. 把结果交给条件码或融合比较路径。

## 边界

- 有符号比较先做二补码解释。
- 无符号比较直接按位宽域比较。

## 行为模型接口

- `compare`
