# Sub Path

## 角色

这一层定义整数减法的主行为。它的数值结果与加法路径共享同一宽度框架，但 C 标志采用 no-borrow 语义，因此必须单独建模。

## 输入

- `a`：被减数。
- `b`：减数。
- `borrow_in`：输入借位，只取 bit0。
- `width`：结果宽度。

## 输出

- `result`：截断差值。
- `n`：结果最高位。
- `z`：结果是否为零。
- `c`：无借位标志。
- `v`：有符号溢出。

## 状态

- 纯组合逻辑。
- 不保存历史借位，所有状态都来自当前输入。

## 处理流程

1. 把 `borrow_in` 合并到减数侧，形成等效被减项。
2. 计算 `a - b_eff` 的二补码结果。
3. 用无符号比较给出 C=1/no-borrow。
4. 用符号位关系给出 V。

## 边界

- `borrow_in` 只影响当前拍。
- `c=1` 表示没有借位，不是进位。
- 溢出只在符号翻转满足减法规则时置位。

## 行为模型接口

- `sub_with_flags`
