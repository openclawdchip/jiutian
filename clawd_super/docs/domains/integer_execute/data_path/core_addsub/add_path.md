# Add Path

## 角色

这一层定义整数加法的主行为。它不仅返回求和结果，还要同时给出进位、符号和溢出，供上层条件执行和标志合并直接使用。

## 输入

- `a`：加数 A。
- `b`：加数 B。
- `carry_in`：输入进位，只取 bit0。
- `width`：结果观察宽度。
- `size64`：是否按 64 位标志解释结果。

## 输出

- `result`：完整截断结果。
- `result32`：低 32 位结果。
- `result64`：64 位结果。
- `cout`：所选宽度下的进位。
- `sign`：结果符号位。
- `overflow`：有符号溢出。

## 状态

- 纯组合逻辑。
- 同时保留 32 位和 64 位双路径结果，方便 W/X 两种写回宽度共享同一个行为入口。

## 处理流程

1. 将输入截断到 64 位可见域。
2. 并行计算 32 位低半和 64 位全宽加法。
3. 根据 `size64` 决定标志位和进位观察窗口。
4. 输出所有可直接用于写回和 flag merge 的字段。

## 边界

- `carry_in` 被强制归一为 0/1。
- 32 位和 64 位的标志判断互不影响。
- 溢出只在被选中的宽度上判断。

## 行为模型接口

- `add_with_flags`
- `alu1_add_unit`
