# Clz Lane

## 角色

这一层负责为除法恢复路径提供前导零计数。它不直接产生商或余数，而是把被除数和除数先拉到同一数量级，为后续对齐、试减和商位选择提供基准。

## 输入

- `value`：待计数的数据。
- `sgn_i`：符号模式开关，决定是否先按位取反再计数。

## 输出

- `count`：前导零个数。
- `normalized_width`：行为模型观察宽度，固定为 64 位。

## 处理流程

1. 将输入截断到 64 位。
2. 若 `sgn_i=1`，先对输入逐位取反。
3. 对处理后的值做前导零计数。
4. 输出用于对齐阶段的计数结果。

## 边界

- 全零输入返回 64。
- 符号模式只改变计数前的数据形态，不改变输出位宽。

## 行为模型接口

- `clz64`
