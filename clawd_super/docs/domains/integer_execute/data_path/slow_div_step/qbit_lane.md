# Qbit Lane

## 角色

这一层负责在迭代除法中给出商位判断。它接收当前部分余数和除数的局部比较结果，形成单步商位选择与辅助控制信号。

## 输入

- `rp_i`：部分余数侧的局部编码。
- `rn_i`：除数侧的局部编码。

## 输出

- `qp`：正向商位候选。
- `qz`：相等判断。
- `qn`：负向商位候选。
- `rp` / `rn`：下一步状态所需的局部编码。

## 处理流程

1. 将输入归一到 3-bit 局部域。
2. 生成正、零、负三种比较判定。
3. 结合比较结果形成下一轮商位控制。
4. 输出给迭代控制层。

## 行为模型接口

- `div_qbit`
- `select_qbit`
