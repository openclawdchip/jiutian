# 产品简介

本文档是九天 APU 的高层产品简介，用于帮助研究者、开发者和潜在贡献者快速理解项目定位。

## 一句话定位

九天 APU 是面向 Agent 生成代码的开源 Agent 原生处理器架构，目标是在逻辑推理、短生命周期 JIT 片段、碎片化并发任务和显式数据搬运场景中提供高执行密度。

## 为什么需要九天

传统 CPU 优先服务人类软件生态：稳定 ABI、完整操作系统语义、复杂缓存一致性和动态控制逻辑。GPU 和 NPU 则更适合规整张量计算。Agentic workload 处在二者之间：它有大量分支、短任务、非规则访存和动态生成逻辑，同时又需要高并发吞吐。

九天的目标是为这类工作负载定义新的执行层。

## 核心价值

- 将人类软件与 Agent 生成代码分离到不同执行域。
- 用控制面保留操作系统、I/O、安全和调度能力。
- 用 Agent 执行面承载显式 SPM、显式 DMA、弱一致性和高并发任务图。
- 用 APU-IR 作为 Agent 代码进入硬件前的稳定契约。
- 用开源规格、模拟器和未来 RTL 支撑社区验证。

## 当前阶段

项目处于 v0.1 种子阶段，当前重点是：

- 完整文档体系。
- 可运行功能模拟器。
- Agent ISA v0.1 草案。
- APU-IR v0.1 草案。
- 任务、capability 和 trace 语义。

## 非目标

- 不追求运行所有传统软件。
- 不把传统缓存一致 SMP 作为 Agent 执行面的默认模型。
- 不用合成峰值 FLOPS 代表系统价值。
- 不在语义未稳定前仓促进入 RTL。
