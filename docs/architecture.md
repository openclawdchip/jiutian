# 架构概览

九天 APU 采用分离式执行模型。

## 控制面

控制面运行在少量高性能超大核上，负责：

- 启动与操作系统执行。
- 设备管理与 I/O。
- 运行时策略。
- Agent 任务准入控制。
- 内存保护与 capability 分配。
- 异常处理与任务终止。

控制面优先考虑兼容性、精确异常、成熟工具链和标准软件语义。

## Agent 执行面

Agent 执行面运行在大量更简单的 Agent 原生核上，负责：

- 短生命周期的生成逻辑。
- 高并发任务图。
- 显式 SPM 分配。
- 显式 DMA 数据搬运。
- 显式同步。
- 弱一致性或软件管理一致性。

Agent 执行面优先考虑执行密度、可预测的本地内存行为和低开销任务分发。

## 为什么要分离执行面？

人类编写的软件需要兼容性、可调试性和稳定接口。Agent 生成的软件可以把
数据流、生命周期和内存放置信息直接暴露给运行时与硬件。

九天把这种差异作为一条一等架构边界。
