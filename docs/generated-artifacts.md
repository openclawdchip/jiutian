# 生成物说明

本文档定义哪些文件可以由工具生成，哪些文件必须人工维护。

## 可生成内容

- 模拟器运行结果。
- trace JSON。
- benchmark 报告。
- 覆盖矩阵草案。
- 后续 RTL 参数文件。

## 不应自动覆盖的内容

- 白皮书。
- 版本化规格。
- README。
- 术语表。
- 安全模型。

## 生成物标记

自动生成文件应包含：

```text
Generated by: <tool>
Source: <input>
Do not edit manually.
```

## 清理策略

生成结果应集中放入 `build/`、`out/` 或 `reports/`，避免污染源码目录。
