## 1. 文档范围和总体目标

Bit-Manipulation，也常简称 bitmanip，是一组面向位级处理的 RISC-V 标准扩展。它把常见的移位加法、位计数、循环移位、字节反转、单比特设置/清除/提取、无进位乘法等操作提升为标准指令。这样做的目标有三类：减少代码尺寸、提升性能、降低能耗。

位操作指令虽然通常具有通用价值，但不同应用领域的需求不同。地址生成更常用于数组索引和指针计算；基础位操作用于编译器内建函数、字符串、位集、加密、哈希和压缩；无进位乘法常见于 CRC、GCM 和有限域运算；单比特操作适合标志位、位图和控制寄存器访问。因此规范把它们拆成若干较小扩展，而不是放入一个大扩展。

## 2. 扩展分类

本规范提交公开评审和批准的扩展包括：

| 扩展 | 中文说明 | 主要用途 |
|---|---|---|
| `Zba` | Address generation instructions，地址生成指令 | 用移位加法加速数组索引和指针地址计算 |
| `Zbb` | Basic bit-manipulation，基础位操作 | 逻辑取反组合、计数、旋转、扩展、min/max、字节操作 |
| `Zbc` | Carry-less multiplication，无进位乘法 | CRC、加密、有限域多项式乘法 |
| `Zbs` | Single-bit instructions，单比特指令 | 清除、设置、反转、提取单个位 |

指令的助记符和编码独立于所属扩展。若多个扩展包含同一条指令，实现时不需要重复硬件逻辑或编码。扩展定义同时覆盖 RV32 和 RV64；多数指令预期能向 RV128 前向兼容。移位立即数字段目前最多 6 位，编码空间中保留了未来 RV128 可能需要的第 7 位。

## 3. 字宽、`.uw` 和后缀规则

在 RV64 中，名称以 `w` 结尾且前面没有点的指令遵循 RV64 word 指令约定：忽略输入高 32 位，把低 32 位作为有符号 32 位值参与运算，产生 32 位结果，并符号扩展到 XLEN。

带 `.uw` 后缀的 bitmanip 指令把某个操作数的低 32 位作为无符号 word 提取并零扩展，再执行 XLEN 宽操作。也就是说 `.uw` 不表示整条指令只产生 32 位结果；除明确说明外，结果仍是 XLEN 宽。

带 `.b`、`.h` 和 `.w` 后缀的指令分别只观察输入低 8 位、16 位和 32 位，并根据具体指令把结果符号扩展或零扩展到 XLEN。

## 4. 指令语义伪代码约定

规范用类似 SAIL 的伪代码描述每条指令。常见记号如下：

| 记号 | 含义 |
|---|---|
| `X(rs)` | 读取整数寄存器 `rs` 的 XLEN 位值 |
| `X(rd) = ...` | 写整数寄存器 `rd` |
| `EXTZ(...)` | 零扩展 |
| `EXTS(...)` | 符号扩展 |
| `XLEN` | 当前整数寄存器宽度 |
| `shamt` | 移位立即数 |
| `index = X(rs2) & (XLEN - 1)` | 从 `rs2` 低位取有效 bit 索引 |

立即数单比特指令在 RV32 中只允许 `shamt[4:0]`；对应 `shamt[5]=1` 的 RV32 编码保留。RV64 可使用 6 位索引访问 0 到 63 位。

## 5. `Zba` 地址生成扩展

`Zba` 扩展已冻结。它用于加速常见数组索引地址生成：把索引左移 1、2 或 3 位后与基地址相加，对应 halfword、word、doubleword 等基本类型数组。选择最多左移 3 位，是因为真实代码中最常见，并且可在简单加法器之外用很少硬件实现，避免拉长关键路径。更大元素宽度仍可使用基础 ISA 的 `slli`，若索引应作为无符号 32 位值解释，则使用本扩展的 `slli.uw`。

`Zba` 指令包括：

| 指令 | RV32 | RV64 | 语义摘要 |
|---|---|---|---|
| `add.uw` | 否 | 是 | `rs1` 低 32 位零扩展后与 `rs2` 做 XLEN 加法 |
| `sh1add` | 是 | 是 | `(rs1 << 1) + rs2` |
| `sh1add.uw` | 否 | 是 | `rs1` 低 32 位零扩展后左移 1，再加 `rs2` |
| `sh2add` | 是 | 是 | `(rs1 << 2) + rs2` |
| `sh2add.uw` | 否 | 是 | `rs1` 低 32 位零扩展后左移 2，再加 `rs2` |
| `sh3add` | 是 | 是 | `(rs1 << 3) + rs2` |
| `sh3add.uw` | 否 | 是 | `rs1` 低 32 位零扩展后左移 3，再加 `rs2` |
| `slli.uw` | 否 | 是 | `rs1` 低 32 位零扩展后按立即数左移 |

实现注意：`sh*add` 可看作移位器前置到加法器输入，通常比通用移位加独立加法更短。`.uw` 变体尤其适合 RV64 上 32 位数组索引和 64 位地址相加。

## 6. `Zbb` 基础位操作扩展

`Zbb` 扩展已冻结，包含最常用的一组基础位操作。

### 6.1 带取反的逻辑操作

| 指令 | 语义 |
|---|---|
| `andn` | `rd = rs1 & ~rs2` |
| `orn` | `rd = rs1 | ~rs2` |
| `xnor` | `rd = ~(rs1 ^ rs2)` |

这些指令减少显式 `not` 加逻辑操作的指令数。它们常用于位掩码、布尔向量、密码和条件位融合。

### 6.2 前导/尾随零计数

| 指令 | RV32 | RV64 | 语义 |
|---|---|---|---|
| `clz` | 是 | 是 | 统计 XLEN 宽值从最高位开始连续 0 的数量 |
| `clzw` | 否 | 是 | 统计低 32 位从 bit 31 开始连续 0 的数量 |
| `ctz` | 是 | 是 | 统计 XLEN 宽值从最低位开始连续 0 的数量 |
| `ctzw` | 否 | 是 | 统计低 32 位从 bit 0 开始连续 0 的数量 |

若输入为 0，结果为被统计宽度，即 `clz/ctz` 返回 XLEN，`clzw/ctzw` 返回 32。软件用途包括规格化、位图扫描、优先级编码、整数 log2 和对齐计算。

### 6.3 置位计数

| 指令 | RV32 | RV64 | 语义 |
|---|---|---|---|
| `cpop` | 是 | 是 | 统计 XLEN 宽值中 1 bit 的数量 |
| `cpopw` | 否 | 是 | 统计低 32 位中 1 bit 的数量 |

`cpop` 常用于位集大小、汉明重量、SIMD 掩码统计、布隆过滤器和密码算法。

### 6.4 整数最小/最大

| 指令 | 比较方式 | 语义 |
|---|---|---|
| `min` | 有符号 | 写入 `rs1` 与 `rs2` 中较小值 |
| `max` | 有符号 | 写入较大值 |
| `minu` | 无符号 | 写入较小值 |
| `maxu` | 无符号 | 写入较大值 |

这些指令避免比较加分支或比较加条件移动序列，有利于分支不可预测的数据处理。

### 6.5 符号扩展与零扩展

| 指令 | 语义 |
|---|---|
| `sext.b` | 取 `rs` 低 8 位并符号扩展到 XLEN |
| `sext.h` | 取 `rs` 低 16 位并符号扩展到 XLEN |
| `zext.h` | 取 `rs` 低 16 位并零扩展到 XLEN |

`zext.h` 在 RV32 和 RV64 都可用；在 RV64 上还常与压缩或数据打包代码配合使用。`zext.w` 不是独立指令，可用 `add.uw rd, rs1, zero` 作为伪指令形式。

### 6.6 循环移位

| 指令 | RV32 | RV64 | 语义 |
|---|---|---|---|
| `rol` | 是 | 是 | XLEN 宽左循环移位 |
| `ror` | 是 | 是 | XLEN 宽右循环移位 |
| `rori` | 是 | 是 | XLEN 宽按立即数右循环移位 |
| `rolw` | 否 | 是 | 低 32 位左循环移位，结果符号扩展 |
| `rorw` | 否 | 是 | 低 32 位右循环移位，结果符号扩展 |
| `roriw` | 否 | 是 | 低 32 位按立即数右循环移位，结果符号扩展 |

循环移位与逻辑移位不同，移出的位从另一端进入。它常用于哈希、密码、校验和、伪随机数生成和位混合。寄存器移位量只取低 `log2(XLEN)` 位；word 变体只取低 5 位。

### 6.7 OR Combine 和字节反转

`orc.b` 对每个字节独立处理：若该字节任意 bit 为 1，则结果对应字节为 `0xff`；否则为 `0x00`。它适合字符串搜索和零字节检测，可与 `ctz` 等组合快速定位。

`rev8` 反转寄存器中字节顺序。RV32 上反转 4 个字节，RV64 上反转 8 个字节。它常用于大小端转换、网络字节序、密码和哈希预处理。

## 7. `Zbc` 无进位乘法扩展

`Zbc` 扩展已冻结，提供 carry-less multiplication。无进位乘法把输入看作 GF(2) 多项式，乘法中的加法用 XOR，不产生进位。它是 CRC、GCM、二进制域密码和纠错码中的核心操作。

| 指令 | 语义 |
|---|---|
| `clmul` | 返回无进位乘积的低 XLEN 位 |
| `clmulh` | 返回无进位乘积的高 XLEN 位 |
| `clmulr` | 返回“反向”对齐的中间高位部分，便于特定 CRC/多项式算法 |

伪代码可以理解为：遍历 `rs2` 的每个 bit；若该 bit 为 1，就把 `rs1` 左移相应位后 XOR 到输出。`clmulh` 和 `clmulr` 选择完整 2*XLEN 位乘积中的不同切片。实现可以复用普通乘法阵列结构，但进位链替换为 XOR 归约；也可以用迭代方式降低面积。

## 8. `Zbs` 单比特扩展

`Zbs` 扩展已冻结，提供单个位的清除、提取、反转和设置。索引来自 `rs2` 或立即数。寄存器索引只使用低 `log2(XLEN)` 位。

| 指令 | 语义 |
|---|---|
| `bclr` | 清除 `rs1` 中由 `rs2` 指定的 bit |
| `bclri` | 清除 `rs1` 中由立即数指定的 bit |
| `bext` | 提取 `rs1` 指定位并写入 bit 0，其余位为 0 |
| `bexti` | 立即数索引版本的 `bext` |
| `binv` | 反转 `rs1` 指定位 |
| `binvi` | 立即数索引版本的 `binv` |
| `bset` | 设置 `rs1` 指定位 |
| `bseti` | 立即数索引版本的 `bset` |

典型操作表达式如下：

| 指令族 | 操作说明 |
|---|---|
| `bclr*` | `rd = rs1 & ~(1 << index)` |
| `bext*` | `rd = (rs1 >> index) & 1` |
| `binv*` | `rd = rs1 ^ (1 << index)` |
| `bset*` | `rd = rs1 | (1 << index)` |

这些指令适合位图、标志寄存器、状态压缩、稀疏布尔集合和协议字段操作。立即数版本能减少动态索引寄存器准备，寄存器版本适合运行时索引。

## 9. 按字母顺序的指令语义

### 9.1 `add.uw`

`add.uw rd, rs1, rs2` 属于 `Zba`，仅 RV64。它把 `rs1` 低 32 位零扩展为 XLEN 宽无符号值，再与 `rs2` 做 XLEN 加法。伪指令 `zext.w rd, rs1` 可展开为 `add.uw rd, rs1, zero`。用途是 32 位索引与 64 位基地址相加。

### 9.2 `andn`

`andn rd, rs1, rs2` 属于 `Zbb`。结果为 `rs1` 与 `rs2` 按位取反后的 AND，即 `rs1 & ~rs2`。常用于掩码清除。

### 9.3 `bclr` / `bclri`

`bclr` 属于 `Zbs`，索引来自 `rs2`；`bclri` 索引来自立即数。它们把 `rs1` 指定位清零，其他位保持不变。RV32 的立即数索引只允许 0 到 31，RV64 允许 0 到 63。

### 9.4 `bext` / `bexti`

`bext` 和 `bexti` 属于 `Zbs`。它们取出 `rs1` 指定位，把该 bit 放入结果 bit 0，结果其他位为 0。可替代右移加 AND 序列。

### 9.5 `binv` / `binvi`

`binv` 和 `binvi` 属于 `Zbs`。它们反转 `rs1` 指定位，其他位保持不变。可用于切换标志位。

### 9.6 `bset` / `bseti`

`bset` 和 `bseti` 属于 `Zbs`。它们把 `rs1` 指定位设置为 1，其他位保持不变。可替代构造 mask 加 OR 序列。

### 9.7 `clmul`

`clmul rd, rs1, rs2` 属于 `Zbc`。它执行无进位乘法并返回低 XLEN 位。乘积加法使用 XOR，因此每个置位乘数位会把被乘数移位后 XOR 到结果。

### 9.8 `clmulh`

`clmulh rd, rs1, rs2` 属于 `Zbc`。它返回无进位乘法完整乘积的高 XLEN 位。适合需要多项式乘积高半部分的算法。

### 9.9 `clmulr`

`clmulr rd, rs1, rs2` 属于 `Zbc`。它返回与 bit 反向或右对齐多项式算法更方便的乘积切片。软件可把它用于 CRC 类算法，减少额外移位和反转。

### 9.10 `clz` / `clzw`

`clz` 属于 `Zbb`，统计 XLEN 宽输入前导零。`clzw` 是 RV64 word 版本，统计低 32 位前导零。输入为 0 时，结果为统计宽度。用途包括规格化、优先级选择和整数对数。

### 9.11 `cpop` / `cpopw`

`cpop` 属于 `Zbb`，统计 XLEN 宽输入中 1 的数量。`cpopw` 是 RV64 word 版本。用途包括位集、掩码、汉明距离和数据压缩。

### 9.12 `ctz` / `ctzw`

`ctz` 属于 `Zbb`，统计 XLEN 宽输入尾随零。`ctzw` 是 RV64 word 版本。输入为 0 时，结果为统计宽度。常用于查找最低置位 bit 和对齐边界。

### 9.13 `max` / `maxu`

`max` 按有符号比较返回较大值，`maxu` 按无符号比较返回较大值。二者属于 `Zbb`，可消除比较后分支或条件选择序列。

### 9.14 `min` / `minu`

`min` 按有符号比较返回较小值，`minu` 按无符号比较返回较小值。二者属于 `Zbb`。

### 9.15 `orc.b`

`orc.b rd, rs1` 属于 `Zbb`。它对 `rs1` 的每个字节分别 OR-combine：只要该字节非零，结果对应字节为全 1；若该字节为 0，结果对应字节为 0。它是零字节检测和字符串函数优化的重要构件。

### 9.16 `orn`

`orn rd, rs1, rs2` 属于 `Zbb`。结果为 `rs1 | ~rs2`。常用于掩码合成和逻辑表达式简化。

### 9.17 `rev8`

`rev8 rd, rs1` 属于 `Zbb`。它按字节反转整个 XLEN 寄存器。RV32 中 bit `[31:24]` 与 `[7:0]` 互换等；RV64 中 8 个字节完全逆序。用于 endian 转换和字节序敏感算法。

### 9.18 `rol` / `rolw`

`rol` 属于 `Zbb`，按 `rs2` 指定移位量左循环移位 XLEN 宽值。`rolw` 是 RV64 word 版本，对低 32 位循环左移后符号扩展到 64 位。

### 9.19 `ror` / `rori` / `rorw` / `roriw`

`ror` 按寄存器移位量右循环移位。`rori` 按立即数右循环移位。`rorw` 和 `roriw` 是 RV64 word 版本，对低 32 位运算并符号扩展。循环移位是哈希和密码中的基础混合操作。

### 9.20 `sext.b` / `sext.h`

`sext.b` 把低 8 位符号扩展到 XLEN。`sext.h` 把低 16 位符号扩展到 XLEN。二者属于 `Zbb`，替代移位再算术右移的序列。

### 9.21 `sh1add` / `sh2add` / `sh3add`

`sh1add`、`sh2add`、`sh3add` 属于 `Zba`。它们分别计算 `(rs1 << 1) + rs2`、`(rs1 << 2) + rs2`、`(rs1 << 3) + rs2`。它们面向 halfword、word、doubleword 数组索引和结构体字段寻址。

### 9.22 `sh1add.uw` / `sh2add.uw` / `sh3add.uw`

这些是 RV64 `Zba` 指令。它们先把 `rs1` 低 32 位零扩展，再左移 1、2 或 3 位并加 `rs2`。适合 32 位无符号索引与 64 位地址计算。

### 9.23 `slli.uw`

`slli.uw rd, rs1, shamt` 属于 RV64 `Zba`。它把 `rs1` 低 32 位零扩展，再按立即数左移。可用于较大元素宽度的无符号 word 索引缩放。

### 9.24 `xnor`

`xnor rd, rs1, rs2` 属于 `Zbb`。结果为 `~(rs1 ^ rs2)`。用于相等 bit 掩码、布尔逻辑和位混合。

### 9.25 `zext.h`

`zext.h rd, rs1` 属于 `Zbb`。它把低 16 位零扩展到 XLEN。用途包括无符号 halfword 数据提取和清除高位。

## 10. RV32/RV64 差异

RV64 增加两类重要差异：

- word 指令：`clzw`、`cpopw`、`ctzw`、`rolw`、`rorw`、`roriw` 等只处理低 32 位，并符号扩展结果。
- `.uw` 指令：`add.uw`、`sh*add.uw`、`slli.uw` 把低 32 位解释为无符号索引，再执行 XLEN 宽地址计算。

RV32 中与 64 位索引相关的编码保留。立即数单比特指令和 `rori` 在 RV32 中使用较窄 shamt，带高位立即数的对应编码保留，避免未来扩展冲突。

## 11. 软件优化用途

### 11.1 `strlen`

字符串长度扫描可按机器字批量加载。典型策略是用 `orc.b` 把每个非零字节变为 `0xff`，零字节保持 `0x00`，再通过反转、取反或 `ctz` 定位第一个零字节。这样可把逐字节循环变成每字一个或少数几个操作。

### 11.2 `strcmp`

`strcmp` 可按机器字比较两个字符串。若两个字相同且没有零字节，继续下一字；若不同或含零字节，通过字节反转、零字节检测和首差异定位确定返回结果。`rev8`、`orc.b`、`ctz`、`minu` 等指令可减少分支和按字节处理。

### 11.3 其他用途

`clz/ctz/cpop` 对位图分配器、调度器、压缩索引和集合操作非常有用。`rol/ror` 对哈希和密码轮函数重要。`clmul*` 可加速 CRC 和 GCM。`bset/bclr/binv/bext` 适合状态位、设备控制位和协议字段。`sh*add` 在编译器后端中可匹配数组寻址表达式。

## 12. 实现注意事项

实现可以按扩展粒度独立声明能力。`Zba` 通常只需在加法器输入前增加小移位路径；`Zbb` 中计数、旋转和字节反转可能需要专用组合逻辑或复用移位网络；`Zbc` 的无进位乘法面积较大，可选择迭代或部分并行实现；`Zbs` 可用 mask 生成加基础逻辑实现。

硬件应保证指令的 XLEN 和 word 语义精确，尤其是 RV64 word 变体的符号扩展、`.uw` 变体的零扩展、立即数保留编码和 `x0` 写丢弃行为。编译器后端应根据 ISA 字符串只在目标支持相应扩展时生成这些指令，并为未支持目标保留基础 ISA 展开序列。
