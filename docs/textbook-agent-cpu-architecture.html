Discipline

为什么需要一门新学科

AI Agent 出现后，计算系统中出现了一类新的执行对象：由 Agent 围绕目标即时生成、即时验证、即时执行、即时回收的短生命周期逻辑。它们由任务流、证据链、工具调用图和状态变换共同组成。

Agentic Workload APU-IR 长期任务记忆 Candidate Commit Recovery Anchor Trace

Agent CPU 体系结构学研究 Agent 生成的代码如何表达为可验证、可调度、可恢复的执行对象。

Core Abstractions

七个基本抽象

任务启动执行，证据提供支撑，投影塑造视图，权限和预算形成边界，trace 保留过程，候选提交给出可审查结果。

任务为什么做，怎样算完成。
证据凭什么判断，如何被检查。
投影当前任务需要看见什么。
权限哪些动作被允许，哪些需要审核。
预算资源如何分配，何时收束。
Trace过程如何复盘，失败如何定位。
候选提交结果如何进入可审查状态。
