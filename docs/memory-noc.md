# Memory 与 NoC 模型

Honeycomb 架构使用显式本地内存与集群化传输，而不是假设所有核心共享一套
完全硬件一致的内存结构。

## 存储层级

1. 每核 Scratchpad Memory（SPM）。
2. 共享 Cluster SRAM。
3. 分布式片上 SRAM 切片。
4. HBM 或主机连接 DRAM 等外部内存。

## 编程模型

Agent 任务应描述：

- 输入与输出区域。
- 本地工作集大小。
- 放置偏好。
- DMA 传输计划。
- Barrier 与依赖点。
- 临时数据生命周期。

## 一致性

超大核域可以使用传统硬件一致性。Agent 域默认使用显式一致性操作：

- `flush` 发布已写入数据。
- `invalidate` 丢弃本地陈旧副本。
- `barrier` 在任务之间建立顺序。
- `fence` 为 DMA 与内存可见副作用建立顺序。

## NoC 方向

NoC 应支持分离的流量类别：

- 控制消息。
- DMA 传输。
- Agent 到 Agent 消息。
- 外部内存流量。
- 异常与 kill 信号。

控制流量必须能够抢占数据流量，从而保证运行时始终保有对生成代码的监管权。
